# Changelog

## 1.0.1

- Adds a collection run button and scheduling switch on the account device.
- Adds collection daily count, last run and next run sensors, with English and Spanish names.
- Keeps collection entities unavailable until the connected CC Tools add-on exposes the collections API.

## 1.0.0

- Initial HACS release.
- Adds account, points, rewards, task and order entities.
- Adds one Home Assistant device per configured printer.
- Adds task switches, manual action buttons and Home Assistant events.
- Includes English and Spanish translations.
